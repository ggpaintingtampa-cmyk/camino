## Home and day lifecycle
Weather/date first; first wake-up routine (shower, breakfast etc); first two appointments; during active day prominent current task; important messages/overdue tasks; expiring envelopes; compact goal/health/money and week/month highlights. Calm and glanceable.
Start Day records wake time, skippable sleep start/quality, morning weight, mood 1–5, energy 1–5 and note. Do not mistake End Day or screen-close time for actual sleep onset. Start time can be corrected.
End Day: pending tasks/appointments/conflicts, optional tomorrow planning using template plus unscheduled tasks, factual editable summary and separate editable personal journal. Can finish with unresolved tasks, returning them to unscheduled list and preserving missed blocks. An open prior day prompts catch-up before starting new day; skip closes it and returns unresolved tasks. Days stay open across midnight until explicitly ended; no automatic truncation of late-night activity. Repeated Start/End must not duplicate records.
Needs attention: unreviewed expired tasks, appointments, open prior day, overlap conflicts, expired envelopes, Lost/Charity obligations, due-soon/overdue goals and manual/AI daily/weekly pins. Priority only; quiet Review Missing Data action walks through missing fields one at a time. No stalled-goal rules in v1 (user explicitly removed them). In-app reminders only, no phone push.

## Schedule and tasks
Full 24-hour schedule, five-minute increments, clearly labeled hours, subtle guides, now line, jump to now. Both touch drag and precise tap form, no requirement to type full dates/times. Today/Tomorrow/date picker, five-minute controls, duration chips. Warn about overlaps, allow, review at night. Date/time America/New_York (Tampa), USD, pounds/miles/Fahrenheit.
Task title and duration required; Work/Personal required default Personal; optional labels, goal, date/time/notes. At time show Ready to start; actual start on press, display clock/end time/minutes remaining/progress. One actual active task at a time with explicit switching. Expired pending blocks prompt Complete / Not completed / Partial / Snooze. Not completed returns full original task duration to unscheduled list and preserves missed history. Partial creates a linked remaining task with user-entered remaining time and optionally day/start time; no forced proportional accounting. Snooze 10m/30m/1h/tonight/custom. Appointments use Attended/Missed/Cancelled and never return to task list. Templates reusable and explicitly applied, no automatic recurrence. Preserve all history on reschedule. Archive instead of destructive removal where useful.

## Goals
Tree of goals/steps with target dates; daily/weekly/monthly/yearly/2-/3-/5-/10-year views. Count completed leaf steps equally, avoiding double counting nested goals. Active/Paused/Completed/Archived. Pinned goals. Due-soon 7 days default. No stalled heuristics. Smaller goals can stand alone. Optional linked tasks reflect completed checklist work without double counting partial replacement tasks.

## Health, practice, journal and history
Daily steps (manual total), multiple timestamped weights in pounds (first after Start Day represents daily trend), workouts activity/duration/notes and day counts, sleep onset/wake/duration/quality, simple meals time/type/description/notes (no calorie lookup), Rocket League duration/practice type/focus/notes. Today/7-day/30-day trends, all historical data retained; larger charts later. Morning mood and energy separately 1–5.
Fact template uses stored wake/check-in, scheduled vs confirmed events, actual tasks, health, goal and money activity; missing is unknown, never fabricated. Preserve editable generated summary separately from own journal, never overwrite edits automatically; explicit regeneration warns. History calendar and search across dates, journal, summaries, tasks, appointments, goals, reminders. All past days accessible.

## Money
Two independent ledgers, Personal and Company. Manually input both Account Total and Available Cash, warnings for disagreement. Account expected = cash + active envelopes + earned + Lost/Charity. Earned and Lost/Charity each separate by source. Amounts integer cents. No bank sync, expense processing, actual transfers or complete net worth in v1.
Envelope source/amount/title/purpose/expiry date AND time/notes. Creation reserves cash; insufficient cash rejected. Expiry visible on Home, choose Earned (matching source earned bucket), Lost/Charity (matching source lost bucket), Extend (new time). Never automatic forfeiture/earn. Expired still reserved until action. Mark Lost/Charity handled when transfer actually made; reduce lost and manual account by amount, retain audit. Cancellation returns active reservation to cash. Every mutation atomic/idempotent; no double money moves. Reasoned manual adjustments with immutable audit; never silently fix reconciliation. Manual displayed balances are tracking values, not bank connection.

## Weather
Primary ZIP 34638; add cities/postcodes and switch forecast location. Server fetching/caching only, general location, no phone GPS. NWS US weather and Open-Meteo geocoding, provider attribution and update/stale labels; network failures never block app. City search requires selection when ambiguous.
