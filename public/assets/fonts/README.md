# Mood emoji

`caminos-mood-emoji.woff2` is a five-character subset of Google's Noto Color Emoji,
downloaded through the official Google Fonts CSS2 API on 2026-09-19. It contains
U+1F610, U+1F614, U+1F62D, U+1F642, and U+1F929, and is served locally so check-ins
do not request third-party resources.

Source: https://fonts.google.com/noto/specimen/Noto+Color+Emoji
